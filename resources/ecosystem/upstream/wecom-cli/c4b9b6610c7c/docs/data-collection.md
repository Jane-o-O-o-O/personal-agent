# 数据收集说明

你使用本 CLI 工具调用企业微信服务时，本工具会在本地读取当前正在调用企业微信接口的 Agent 程序名称，并将调用链路随服务请求回传至企业微信云端，用于协助用户定位使用中遇到的问题，并提升用户服务体验。

## 收集内容

- 调用企业微信接口时，所在的 Agent 程序名称（进程名）及其调用链路。

## 收集目的

- 协助定位使用过程中遇到的问题。
- 提升用户服务体验。

**默认行为**：上述回传由编译特性 `call-chain` 控制，默认开启。通过 `npm install -g @wecom/cli` 安装的预编译版本默认开启此能力。

如你不希望回传 Agent 程序名称，需从源码构建并关闭该特性后重新构建：

```bash
cargo build -p wecom-cli --no-default-features
```

重新构建后，相关能力及其依赖不会被编译进产物，也不再回传上述信息。
