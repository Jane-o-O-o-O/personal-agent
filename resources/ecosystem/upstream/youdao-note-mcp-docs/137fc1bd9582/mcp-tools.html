概述 ​

有道云笔记提供MCPserver， 只需开发者简单配置，即可调用智能体查询、读取、创建笔记内容，以及生成精美的文转图。

账号准备 ​

你需要先在网易智能开发者平台 注册，获取你的API key。 目前你只能获取注册手机号下有道云笔记的内容权限。

安装 ​

要在Claude桌面版中使用，请添加服务器配置：

在MacOS上：~/Library/Application Support/Claude/claude_desktop_config.json 在Windows上：%APPDATA%/Claude/claude_desktop_config.json

json
"servers": {
        "ynote": {
            "type": "sse",
                "url": "https://open.mail.163.com/api/ynote/mcp/sse",
                "headers": {
                "x-api-key": "{api_key}"
            },
            "dev": {
                "watch": "build/**/*.js",
                    "debug": { "type": "node" }
            }
        }
    }

功能 ​

  • [x] 创建笔记 - 创建新笔记并保存到指定目录
  • [x] 获取目录列表 - 获取目录下的笔记和文件夹列表，支持分页
  • [x] 获取笔记内容 - 获取指定笔记的文本内容
  • [x] 搜索笔记 - 搜索笔记标题和内容，支持分页
  • [x] 网页剪藏 - 智能提取网页内容并保存为笔记
  • [x] 最近收藏笔记 - 获取最近收藏笔记列表
  • [ ] 文本转图表 - 将文本转换为流程图、思维导图等业务图表

调试 ​

由于MCP服务器通过标准输入输出进行通信，调试可能会具有挑战性。我们建议使用MCP检查器，它作为包脚本可用：

npm run inspector

检查器将提供一个URL，您可以在浏览器中访问调试工具。

能力介绍 ​

创建笔记 ​

创建新笔记并自动保存到"我的资源"目录（不存在时保存到根目录）

输入title (笔记标题，必填，长度限制0-80字符，不能含有特殊符号 \ / : * ? " < > |)，content (笔记内容，可选，不提供则创建空笔记)
输出创建成功提示信息

获取目录列表 ​

获取指定目录下的笔记和文件夹列表，支持分页查询

输入parentId (目录ID，'0'=根目录，其他值=具体目录ID)，lastId (分页游标，可选，首次查询不传)
输出entries (条目列表，每个条目包含：id-条目唯一标识、name-笔记标题或文件夹名称、version-版本号、parentId-父目录ID、dir-类型标识true为文件夹false为笔记)，totalCount (总数量)

获取笔记内容 ​

获取指定笔记的文本内容

输入fileId (笔记文件ID，必填，从目录列表或搜索结果获取)
输出fileId (笔记ID)，content (笔记文本内容)

搜索笔记 ​

搜索笔记内容，支持分页查询，每页固定15条数据

输入keyword (搜索关键词，必填，支持搜索笔记标题和内容)，startIndex (起始索引，可选，不传默认从0开始)
输出entries (匹配的笔记列表，每个条目包含：id-条目唯一标识、name-笔记标题或文件夹名称、version-版本号、parentId-父目录ID、dir-类型标识true为文件夹false为笔记)，totalCount (总数量)

网页剪藏 ​

智能提取指定URL的网页内容并保存为有道云笔记，自动识别网页标题、正文、图片等核心信息

输入url (要剪藏的网页URL地址，必填，支持HTTP/HTTPS协议)，parentId (保存目录ID，可选，默认保存到"我的资源/收藏笔记"文件夹)
输出剪藏成功提示信息

最近收藏 ​

查询用户最近收藏的笔记列表

输入limit (返回条数限制，可选，默认50，最多50)
输出返回数组，每项字段：fileId（笔记ID）、title（标题）、content（笔记文本内容）、createTime（收藏时间戳，毫秒）

保存任意类型笔记 ​

创建任意类型笔记，支持HTML内容和可选图片。灵活的笔记创建工具，可用于保存富文本内容、网页片段或带图片的文档，保存到'我的资源/收藏笔记'文件夹

输入title(标题-带后缀名)，type(笔记类型)，content(笔记本体)
输出fileId（笔记ID）

带图片的网页剪藏工具 ​

带图片的网页剪藏工具，将已提取的HTML内容及图片base64数据一起保存为有道云笔记。适用于客户端已抓取好网页内容和图片资源的场景，图片直接随内容上传无需服务器二次下载，保存到'我的资源/收藏笔记'文件夹

输入title(笔记标题，必填)，bodyHtml(网页HTML正文内容，必填。图片仍使用原始URL引用，实际图片数据通过images参数传入)，sourceUrl(原始网页URL，必填。用于记录内容来源)，images（图片资源JSON数组字符串，必填。格式：[{"url":"图片原始URL","mimeType":"image/png","data":"base64数据"}]）
输出fileId（笔记ID）
