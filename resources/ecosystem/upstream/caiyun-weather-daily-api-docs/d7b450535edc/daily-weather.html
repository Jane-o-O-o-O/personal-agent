    天级别预报 ​

    天级别预报接口，返回目标位置未来多天的逐日天气预报，含全天/白天/夜晚分段变量、空气质量、生活指数与日出日落时间。

    更新频率与空间分辨率 ​

    逐日数据为批次发布（通常 2-4 次/日），空间分辨率为 9-13 km 级（由逐小时聚合），时间范围为未来十五天逐日。生活指数时间范围为未来十五天逐日。详情见 时空变量覆盖情况。

    请求 ​

    http
    GET https://api.caiyunapp.com/v2.6/{token}/{经度},{纬度}/daily

    路径参数 ​

    参数说明
    tokenAPI 认证凭证，详见 认证与鉴权
    经度目标地点经度
    纬度目标地点纬度

    注意：URL 路径中经度在前、纬度在后（如 101.6656,39.2072）；响应中的 location 字段为 [纬度, 经度] 顺序（如 [39.2072, 101.6656]）。

    查询参数 ​

    参数必填默认值取值范围说明
    lang否zh_CNzh_CN/zh_TW/en_US/en_GB/ja/ug/bo自然语言描述的语言，未匹配时回落 zh_CN，见 语言
    unit否metricmetric/metric:v1/metric:v2/SI/imperial单位制，其他取值返回 422，见 单位制
    alert否falsetrue/falsealert=true 且 token 具备预警权限时，响应附带 result.alert，见 预警数据
    callback否——JSONP 回调函数名
    dailysteps否51~16返回的天数；通常为 1~15 天，dailysteps=16 需配合 dailystart=-1；实际上限由套餐决定，超出套餐上限时按套餐上限返回
    dailystart否0-1、0仅支持 -1 和 0（-1 表示回退一天），其他取值返回 422

    响应字段 ​

    JSONPath类型说明
    $.result.daily.temperature[]array<object>全天地表 2 米气温；每项包含 max、min、avg
    $.result.daily.temperature_08h_20h[]array<object>白天地表 2 米气温；每项包含 max、min、avg
    $.result.daily.temperature_20h_32h[]array<object>夜晚地表 2 米气温；每项包含 max、min、avg
    $.result.daily.pressure[]array<object>地面气压；每项包含 max、min、avg
    $.result.daily.humidity[]array<object>地表 2 米相对湿度(0-1)；每项包含 max、min、avg
    $.result.daily.wind[]array<object>全天地表 10 米风，max/min/avg 均含 speed（风速）与 direction（风向）
    $.result.daily.wind_08h_20h[]array<object>白天地表 10 米风，结构同上
    $.result.daily.wind_20h_32h[]array<object>夜晚地表 10 米风，结构同上
    $.result.daily.precipitation_08h_20h[]array<object>白天降水数据；每项包含 max、min、avg、probability
    $.result.daily.precipitation_20h_32h[]array<object>夜晚降水数据；每项包含 max、min、avg、probability
    $.result.daily.precipitation[]array<object>全天降水数据；每项包含 max、min、avg、probability
    $.result.daily.cloudrate[]array<object>云量(0.0-1.0)；每项包含 max、min、avg
    $.result.daily.dswrf[]array<object>向下短波辐射通量(W/M2)；每项包含 max、min、avg
    $.result.daily.visibility[]array<object>地表水平能见度；每项包含 max、min、avg
    $.result.daily.skycon[].valuestring全天主要 天气现象
    $.result.daily.skycon_08h_20h[].valuestring白天主要 天气现象
    $.result.daily.skycon_20h_32h[].valuestring夜晚主要 天气现象
    $.result.daily.life_index.ultraviolet[]array<object>紫外线指数，index 为字符串，取值 "0"-"5"（含 "0"=无，夜间），desc 语义见 生活指数
    $.result.daily.life_index.comfort[]array<object>舒适度指数，index 为字符串，取值 "0"-"13"，desc 语义见 生活指数
    $.result.daily.life_index.carWashing[]array<object>洗车指数，index 为字符串，取值 "1"-"4"，desc 语义见 生活指数
    $.result.daily.life_index.coldRisk[]array<object>感冒指数，index 为字符串，取值 "1"-"4"，desc 语义见 生活指数
    $.result.daily.life_index.dressing[]array<object>穿衣指数，index 为字符串，取值 "0"-"8"，desc 语义见 生活指数
    $.result.daily.air_quality.pm25[]array<object>PM2.5 浓度(μg/m3)；每项包含 max、min、avg
    $.result.daily.air_quality.aqi[]array<object>国标 AQI，max/min/avg 均含 chn 与 usa
    $.result.daily.astro[]array<object>日出日落时间为当地时区的时刻；每项包含 sunrise、sunset

    对于 xxx, xxx_08h_20h, xxx_20h_32h:

    • xxx 表示全天，0时～24时的
    • xxx_08h_20h 表示当天 08～20 时
    • xxx_20h_32h 表示当天 20～次日 08 时的

    备注：

    • 对于全天变量 xxx.avg，在当日，表示的是从当前整点小时至当天结束的平均值，而不是全天的平均值；例外是 wind.avg（含 direction），恒为全天 24 小时的均值。
    • xxx_08h_20h.avg 与 xxx_20h_32h.avg 恒为完整 12 小时窗口的均值；max/min 始终为对应完整时段窗口的极值。

    错误 ​

    接口错误统一返回如下结构，HTTP 状态码与含义详见 错误信息。

    json
    {
  "status": "failed",
  "error": "token is invalid",
  "api_version": "2.6"
}
