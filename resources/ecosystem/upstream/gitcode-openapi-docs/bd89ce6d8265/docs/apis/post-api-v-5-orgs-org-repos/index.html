创建仓库

POST 
/api/v5/orgs/:org/repos

Request​

Path Parameters

    org stringrequired

    组织的路径(path/login)

Query Parameters

    access_token stringrequired

    用户授权码

  • application/json

Body

    namestringrequired

    仓库名称

    descriptionstring

    仓库描述

    homepagestring

    主页

    has_issuesboolean

    允许提Issue与否。默认: 允许(true)

    has_wikiboolean

    提供Wiki与否。默认: 提供(true)

    can_commentboolean

    允许用户对仓库进行评论。默认： 允许(true)

    publicinteger

    仓库开源类型。0(私有), 1(公开)

    auto_initboolean

    值为true时则会用README初始化仓库。默认: 不初始化(false)

    gitignore_templatestring

    Git Ignore模版

    license_templatestring

    License模版

    pathstring

    仓库路径

    default_branchstring

    初始化项目时的默认分支名称。默认: main

    import_urlstring

    导入项目的git地址，import_url和project_template参数只能传入一个

    project_templatestring

    模板项目的path，import_url和project_template参数只能传入一个

    repository_typestring

    仓库类型。code:代码仓，model:模型仓，dataset:数据集仓，space:space，默认code

Responses​

  • 200

成功响应
