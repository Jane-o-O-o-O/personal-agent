获取单个Pull Request

GET 
/api/v5/repos/:owner/:repo/pulls/:number

Request​

Path Parameters

    owner stringrequired

    仓库所属空间地址(组织或个人的地址path)

    repo stringrequired

    仓库路径(path)

    number integerrequired

    第几个PR，即本仓库PR的序数

    Example: 0

Query Parameters

    access_token string

    用户授权码

Responses​

  • 200

成功响应
