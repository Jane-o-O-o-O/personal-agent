获取看板内容列表

GET 
/api/v5/org/:owner/kanban/:kanban_id/item_list

Request​

Path Parameters

    owner stringrequired

    组织的路径

    kanban_id stringrequired

    看板id

Query Parameters

    access_token string

    用户授权码

    repo string

    仓库路径

    source_type string

    来源类型：issue/merge_request

    source_status string

    来源状态：opened/closed/merged

    title string

    标题

    source_iids string

    使用pr或者issue的iid进行查询, 使用该参数必须填写repo参数，否则不生效

    page string

    分页参数，第几页

    per_page string

    分页参数，每页数量
