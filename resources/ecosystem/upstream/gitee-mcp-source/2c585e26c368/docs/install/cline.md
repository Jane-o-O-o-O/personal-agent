# Cline

Add the remote MCP server in Cline MCP settings:

```json
{
  "mcpServers": {
    "gitee": {
      "url": "https://api.gitee.com/mcp",
      "headers": {
        "Authorization": "Bearer <your personal access token>"
      },
      "disabled": false,
      "autoApprove": []
    }
  }
}
```
