更新日期：2026-10-04。这里管理个人 Agent 可见的连接器、官方远程 MCP，以及尚待开发的生态资料。页面中的「安装」表示将一个**已适配的能力**接入本项目的 Pi 运行时；它不安装归档源码，也不代表平台账号已获业务权限。

## 目录和可运行能力是两层

[生态资源库](../resources/ecosystem/README.md)有 78 条开发资产，包含源码快照、Skill 发布包、MCP/CLI 包、数据和 API 文档。同一平台可能占多条；数量既不是平台数，也不是已安装工具数。管理页读取这些资产的名称、类别、来源、账号要求及限制，用于搜索和核对。`upstream/` 中的文件不会因浏览条目或点击安装而被执行；部分 Skill 是 OpenClaw 专用说明，不能原样加载到 Pi。

从工作台「生态扩展」（`#ecosystem`）进入，可按类别、名称和状态筛选。可安装项另由应用内受控适配器定义。首批范围是已经存在的查询连接器，以及经过显式接入的官方 Streamable HTTP MCP。没有适配器或可用授权路线的条目仅显示资料和限制，不提供可运行的「安装」按钮；已有适配器但缺用户凭据的条目会提供配置表单。卡片区分「已启用」「需凭据」「可安装」「已归档」「仅参考」；只有应用实际保存并加载配置后，才能显示为已启用。连接测试、真实工具执行和业务结果分别记录，不能互相替代。

## 安装与卸载的产品语义

管理页调用同源、需登录的后端接口。服务端根据明确的适配器白名单决定能否安装，并校验所需配置；不能通过传入任意 URL、命令或归档路径，让网页驱动 VPS 执行第三方代码。密钥仅在后端加密保存，页面只显示是否已经配置；错误、事件、Pi 会话和普通日志不应包含密钥或带凭据的 MCP URL。

安装远程 MCP 时，后端先做协议初始化和工具列表探测，并将实际可用性与账号业务权限分开显示。启用后的配置由**该 VPS 应用实例**加载到 Pi 的 MCP 扩展，后续任务或新建会话才能发现工具。模型对 MCP 的真实调用仍走项目批准流程；安装本身不批准叫车、下单、写文档或付款。正在运行的任务不承诺热更新工具列表。

卸载只取消这个应用对能力的加载，保留归档资料和历史任务，也不代替去厂商后台撤销 Token、取消真实订单或退款。受控远程 MCP 卸载会删除该实例保存的连接凭据；现有内建连接器卸载则关闭工具，保留配置供再次启用。用户自定义 MCP 与受控生态 MCP 各自管理；卸载一项生态能力不能覆盖或删除自定义 MCP 的配置。平台侧凭据撤销、账号退出及远端数据删除如需执行，应另设可核对的专门流程。

## VPS 验收边界

工作台和 Pi 服务同在应用容器，浏览器容器保留独立权限；业务凭据不挂载到浏览器容器。目录可以部署到 VPS，但归档文件不会自动变成 Pi 工具。上线验收至少包括：未登录无法读写管理接口；缺凭据时不能启用；不可安装项拒绝写入；同一实例的新任务能发现刚启用的工具；卸载后新任务不再发现；批准前不能调用受控 MCP；响应和日志无明文密钥。

2026-10-04 公网 VPS 验收：未登录目录读写均返回 401；登录后目录为 94 条，其中 78 条归档、12 条可安装适配器、4 条参考规划。三家外卖、WPS 和归档资产安装均返回 409，滴滴缺 Key 安装也返回 409。原本启用的日历在公网完成卸载、再安装；应用容器再次重启后仍为启用。桌面和 390px 公网页面已实际打开，滴滴详情显示「需凭据」，页面无横向溢出或 JS 异常。应用容器 12 项源码/前端文件与本地哈希一致，模型和 Resend 的加密配置核对保持不变。

本地隔离的 Fastify/工作台验收为 122/122 项单元及集成测试、12/12 项网页端到端测试，临时目录与端口已清理。Pi SDK 对受控滴滴 MCP 的测试替身完成 `initialize`/`tools/list`，只向模型暴露允许的地点查询工具，隐藏了创建订单工具；伪造隐藏下单调用时上游执行次数仍为 0。瑞幸和飞常准的本地 MCP 替身也验证了握手及认证头。这些测试只证明本项目的目录、工具发现和批准链路，**没有使用滴滴、瑞幸或飞常准真实账号做握手或业务查询**，更不代表订单或付款成功。详细证据见[全量功能测试报告](full-functional-test-report.md)。
